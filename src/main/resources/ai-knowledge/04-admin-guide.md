# 管理员操作指南

## 用户与班级

- **用户管理**：创建、停用账号，分配学生或教师角色。
- **班级管理**：创建班级，维护学生名单。

## 系统维护

- **日志查看**：查看操作审计记录。
- **证书管理**：配置证书模板，管理颁发规则。
- **考试管理**：对全站考试有完整管理权限。

## API 连接配置（AI）

路径：侧边栏 **API 连接配置**（仅管理员可见）。

1. 首次使用前在数据库执行 `sql/alter_t_ai_platform_config.sql`。
2. 填写 OpenAI 兼容 **基础 URL**（如硅基流动 `https://api.siliconflow.cn/v1`）与 **API 密钥**。
3. 点击 **测试连接**，从列表选择 **模型**，开启 **启用** 后 **保存**。
4. 保存后全站 AI 助手、AI 阅卷、成绩简报等均使用该配置。

密钥在界面中脱敏显示；再次保存时密钥留空表示不修改原密钥。

## AI 助手说明

配置启用后，教师与学生可使用 **AI 助手** 咨询系统操作。助手基于内置操作说明知识库回答，不访问题库与答卷数据。
