# 教师端操作指南

## 题库与试题

- **题库管理**：新增、编辑、删除题目；支持单选、多选、判断、简答及材料题（共用题干多小问）。
- **题目分类**：为题目打标签，便于组卷筛选。
- **试题仓库**：按类别组织题目集合。
- 支持 Excel 批量导入（使用 `public/template/ImportQuestionTemplate.xlsx` 模板）；也支持 JSON 导入（须符合后端规范文档）。

## 考试与阅卷

- **考试管理**：创建考试，设置时间、选题、分值、及格线等。
- **阅卷评分**：在待阅列表中打开答卷；客观题已自动得分，**简答题**需教师打分或点击 **AI 阅卷** 获取建议分与说明，确认后 **提交批改** 方为正式成绩。
- **成绩统计**：查看班级成绩；进入详情可查看分档、及格率，并 **生成 AI 简报**（文字分析报告）。

## 班级与公告

- **班级管理**：查看班级学生，分配考试范围。
- **公告通知**：向班级发布通知。

## 注意事项

- AI 阅卷结果为建议分，教师应复核后提交。
- 助手不提供题库中具体题目与答案，仅说明操作步骤。
