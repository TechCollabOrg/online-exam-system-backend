# 学生端操作指南

## 参加考试

1. 登录后进入 **试卷中心**，查看本班级已发布的考试。
2. 点击 **开始考试** 进入答题页；考试过程中请勿频繁切屏（会被记录）。
3. 答完后点击 **交卷**；客观题自动批改，简答题需等待教师阅卷。
4. 在 **考试记录** 中查看分数与答题详情（教师开放后可见解析）。

## 刷题与错题本

- **刷题中心**：选择练习题库，随时练习，不计入正式考试成绩。
- **错题本**：系统自动收录答错的题目，可反复练习。

## 讨论区与个人中心

- **讨论区**：可向老师或同学提问学习相关疑问（勿在讨论区发布考试答案）。
- **个人中心**：修改头像、昵称、密码。
- **我的证书**：查看通过考试后颁发的电子证书。

## AI 助手

侧边栏 **AI 助手** 可咨询系统使用方法、各功能入口说明。助手不知道具体考题内容，也无法查询你的成绩数据。
