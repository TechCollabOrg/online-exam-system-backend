# AI 功能说明

## AI 助手

- 入口：侧边栏 **AI 助手**（学生、教师、管理员均可使用，需管理员已配置并启用 API）。
- 能力：解答「系统怎么用」类问题，支持多轮对话；回答基于操作说明知识库。
- 限制：不透露具体试题、标准答案、学生作答或成绩明细；不代替教师阅卷决策。

## AI 主观题阅卷

- 入口：教师 **阅卷评分** 页面，对含简答题的答卷点击 **AI 阅卷**。
- 说明：给出建议分与 **【AI阅卷】** 开头的说明；教师修改后须 **提交批改** 才计入正式成绩。
- 范围：当前仅顶层简答题（qu_type=4）；复合题子简答暂未纳入。

## 成绩分析 AI 简报

- 入口：成绩统计 → 查看详情 → **生成简报**。
- 说明：根据班级统计生成文字报告，供教学参考。

## 配置优先级

管理员在库中保存并启用的 API 配置 **优先于** 服务器 `env.local` 中的 LLM 环境变量。
